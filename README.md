# Hospital Appointment Management System

## Description

An ASP.NET Core MVC application developed to display
doctor information and manage patient appointment requests.

## Technologies Used

- ASP.NET Core MVC
- C#
- HTML
- Razor Views
- .NET
- Git & GitHub

## Features

- Display doctor information
- Calculate total consultation charge
- Extension method
- Asynchronous API request
- Patient name using Cookie
- Selected specialization using Session
- Doctor ID using Query String
- Doctor ID using Hidden Field
- Response caching
- Memory caching
- Patient appointment request

## API Used

JSONPlaceholder Posts API
